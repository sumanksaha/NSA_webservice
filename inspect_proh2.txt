5: // This is the SECOND document for an UNSAFE sample. It is rendered by its own
6: // endpoint (download_prohibition_order_docx) and is addressed to the food
7: // business operator (manufacturer). It is NOT issued for retailer-cum-manufacturer

9: // product has no separate manufacturer and no batch/manufacturing/expiry
10: // details. The prayer (Unsafe_file.adoc) is still generated for RCM cases.
11: //
12: // The first document for an unsafe case is the prayer (Unsafe_file.adoc). This
13: // letter repeats the first paragraph of the prayer (the sample description) so
14: // that the prohibition letter is self-contained.

22: //   per_packet_sample_quantity → computed in routes.py (sample_quantity / packet_count)
23: //   batch_no           → batch_no               / batch_no
