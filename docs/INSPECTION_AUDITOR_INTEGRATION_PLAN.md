## 1. Executive Summary

This document specifies how to integrate the **FBO Compliance Auditor Agent** directly into the **Inspection Lifecycle** and the **Section 32 Improvement Notice Generation Pipeline**.

### Current Limitations:
- `derive_actions()` in `app/shared/context_derivers.py` outputs static, generic single-line directives.
- Improvement Notices generated by `app/food_cell/renderer.py` lack granular, operational SOPs, phased milestones, and exact verification criteria.
- Open inspections remain unresolved in `/inspection/open` because FBOs lack clarity on what evidentiary dossier is required for the FSO to mark *"Corrective Measures Implemented"*.

### Proposed Solution:
1. **Dynamic CAPA Generation**: The Auditor Agent evaluates the 12-item inspection checklist violations and generates a 3-phase Corrective and Preventive Action (CAPA) workflow.
2. **Improvement Notice Annexure A**: The rendered Section 32 Improvement Notice (HTML/PDF/Asciidoc) includes the full Auditor CAPA Roadmap and evidentiary requirements.
3. **Streamlined Re-inspection & Closure**: The FSO uses the generated *Dossier Checklist* to verify compliance and close the issue in one click.

### Step 2: Inspection Controller & Auditor Trigger (`app/inspection/routes/inspection_routes.py`)

Add the endpoint to trigger plan generation:

```python
# app/inspection/routes/inspection_routes.py
import json
from flask import flash, redirect, render_template, url_for
from app.extensions import db
from app.inspection import inspection_bp
from app.models import Inspection
from app.shared.context_derivers import derive_violations
from app.auditor.service import FBOAuditorAgent


@inspection_bp.route("/<int:inspection_id>/auditor-plan", methods=["GET", "POST"])
def generate_auditor_plan(inspection_id: int):
    inspection = Inspection.query.get_or_404(inspection_id)
    violations = derive_violations(inspection)

    if not violations:
        flash("No violations found on this inspection record.", "info")
        return redirect(url_for("inspection.open_issues"))

    # 1. Build FBO context
    fbo_context = {
        "fbo_name": inspection.fbo_name,
        "business_type": getattr(inspection, "premises_type", None) or "General Food Establishment",
        "scale": "Standard FBO",
        "compliance_deadline_days": 15,
        "shortcomings": [
            {
                "item": v.get("field", "general"),
                "observation": v.get("title", "Checklist non-compliance"),
                "severity": "major",
            }
            for v in violations
        ],
    }

    # 2. Invoke Auditor Agent
    auditor_service = FBOAuditorAgent()
    plan = auditor_service.generate_remediation_plan(fbo_context)

    # 3. Persist to inspection record
    inspection.auditor_plan_json = json.dumps(plan)
    db.session.commit()

    return render_template(
        "inspection/auditor_plan_view.html",
        inspection=inspection,
        plan=plan,
    )
```

### Step 3: Improvement Notice Context & Renderer Integration (`app/food_cell/renderer.py`)

Update `DODocumentRenderer.build_improvement_notice_context` to support the dynamic plan:

```python
# app/food_cell/renderer.py
import json


def build_improvement_notice_context(
    self,
    inspection: Any,
    violations: list[dict[str, str]] | None = None,
    actions: list[str] | None = None,
    compliance_deadline: str | None = None,
    enclosures: list[str] | None = None,
    is_inspection_report: bool = False,
) -> dict[str, Any]:
    # Extract saved auditor plan if present
    auditor_plan = None
    if getattr(inspection, "auditor_plan_json", None):
        try:
            auditor_plan = json.loads(inspection.auditor_plan_json)
        except Exception:
            auditor_plan = None

    return {
        "fbo_name": getattr(inspection, "fbo_name", None),
        "fbo_address": getattr(inspection, "fbo_address", None),
        "inspection_date": (
            inspection.inspection_date.strftime("%d/%m/%Y") if getattr(inspection, "inspection_date", None) else None
        ),
        "fbo_fssai": getattr(inspection, "fssai_license", None),
        "fso_name": getattr(inspection, "fso_name", None),
        "notice_date": datetime.now(UTC).strftime("%d/%m/%Y"),
        "improvement_notice_ref": getattr(inspection, "inspection_code", None),
        "violations": violations or [],
        "actions": actions or [],
        "auditor_plan": auditor_plan,  # Injected CAPA Plan
        "compliance_deadline": compliance_deadline,
        "enclosures": enclosures or [],
        "is_inspection_report": is_inspection_report,
    }
```

### Step 5: Verification & Issue Closure (`app/inspection/routes/derived_views.py`)

Provide an auditable closure action in the derived inspection views:

```python
# app/inspection/routes/derived_views.py
from datetime import UTC, datetime
from flask import flash, redirect, request, url_for
from app.extensions import db
from app.inspection import inspection_bp
from app.models import Inspection


@inspection_bp.route("/<int:inspection_id>/verify-closure", methods=["POST"])
def verify_closure(inspection_id: int):
    """Closes inspection after verifying that the FBO submitted the required auditor dossier."""
    inspection = Inspection.query.get_or_404(inspection_id)

    inspection.is_dismissed = True
    inspection.dismissed_at = datetime.now(UTC)
    inspection.dismissal_reason = "Auditor CAPA Dossier verified by FSO."
    inspection.dossier_verified = True

    db.session.commit()
    flash(f"Inspection {inspection.inspection_code} closed: Corrective measures verified.", "success")
    return redirect(url_for("inspection.open_issues"))
```
