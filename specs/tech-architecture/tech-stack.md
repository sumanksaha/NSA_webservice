# Project Context

## Stack

- **Language/Runtime:** Python 3.12 (`.python-version` = 3.12; `runtime.txt` also present for Render)
- **Web Framework:** Flask 2.x (via `app.py` WSGI entry point; `app:create_app` factory)
- **ORM:** Flask-SQLAlchemy 2.x (`db = SQLAlchemy()` singleton in `app/extensions.py`)
- **Migrations:** Flask-Migrate / Alembic (27+ migration files in `migrations/versions/`, newest: `fix_rbac_tables.py`)
- **Database:** PostgreSQL primary (Render managed `nsa-webservice-db`); SQLite (`instance/app.db`) fallback for local dev
- **Task Queue:** Dual model — Celery 5.x + Redis broker (for heavy jobs like PDF generation; `celery_app.py` factory `make_celery`) **and** Upstash QStash (serverless webhook-based queue; zero local worker needed on Render free tier)
- **PDF Generation:** WeasyPrint (via centralized `app/utils/pdf_utils.py::generate_pdf_from_html`; defensive `import_weasyprint()` guard because the app must boot without GTK)
- **Templating:** Jinja2 + Vanilla JS + Quill 2.x (server-rendered; no React build pipeline)
- **Auth:** Flask-Login (`login_manager`) + Flask-WTF CSRF (`csrf`); RBAC scaffolding exists (`app/models/auth.py`: `Role`, `user_roles`, `Comment`) but is not yet wired into route enforcement (Phase 18)
- **Security:** Flask-Talisman (CSP, HSTS, referrer-policy); `ProxyFix` for TLS-termination at edge
- **Search:** SQLite FTS5 (auto-index via session hooks in `app/search/`); `LIKE` fallback on PostgreSQL; fuzzy fallback via `rapidfuzz`
- **OCR:** Multi-engine pipeline (`app/ocr_pipeline/`): OCRDecisionEngine (detect selectable text) → ImagePreprocessor → PageDetector (tables/stamps/signatures) → OCREngine (EasyOCR primary + pytesseract fallback)
- **Vector Store / RAG:** Qdrant (`qdrant-client>=1.9.0`; local or Qdrant Cloud via `RAG_QDRANT_URL`/`API_KEY`)
- **Embeddings:** `sentence-transformers>=3.0.0` (all-mpnet-base-v2, 768-dim) locally; **or** remote via Modal TEI `/embed` endpoint (`RAG_EMBED_ENDPOINT` — used on Render free tier where local torch OOMs the 512MB instance)
- **Reranker:** Cross-encoder (`cross-encoder/ms-marco-MiniLM-L-6-v2` or fine-tuned local) **or** remote TEI `/rerank` (`RAG_RERANKER_ENDPOINT`); plus a deterministic rule-based `sec_act` legal-feature reranker (`EnsembleReranker`) that is the strongest single reranker measured (R@10 0.474)
- **Graph DB:** Neo4j Aura (`neo4j` Python driver in `app/services/neo4j_graph.py`); legal sub-graph (`kg/` package: schema, corpus_ingestion, enrichment, queries, hybrid) separate from case-file entity graph
- **AI Assistant (Phase 11):** httpx-based LLM client calling OpenRouter/OpenAI-compatible endpoints (`app/ai_assistant/service.py::AIAssistantService`)
- **LangGraph Agent (M3+/M5):** `langgraph>=1.0.0` + `langgraph-checkpoint-postgres>=3.0.0` + `psycopg-binary>=3.1.0` (lazy imports — never on the legacy pipeline path)
- **Sync Targets (multi-target sheets redundancy — Priority 7):** Google Sheets (gspread, primary) + Airtable (pyairtable, active) + MS Excel Online (msal, dormant — `ENABLE_EXCEL_SYNC=false`)
- **Cloud Storage:** Cloudflare R2 / Backblaze B2 (`boto3`) **or** Cloudinary (photo evidence); branching via `app/utils/storage.py`
- **Other notable deps:** `numpy` (runtime undeclared dep for OCR pipeline), `PyMuPDF/fitz` + `pdfplumber` + `pdf2image` + `Pillow` (PDF/image processing), `fastembed` (BM25 sparse, optional), `qrcode` (QR in PDFs), `num2words` (amount-to-words)
- **Rust accelerator:** `rust/` package (PyO3 `nsa_rust` cdylib) for legal text normalization; built via `maturin`, imported optionally by `legal_paragraph_detection_engine/src/`
- **Linting/Formatting/Tooling:** Ruff (lint + format), Black (formatter, line-length 120), Mypy (type check), Pyright, Bandit, isort (via Ruff), vulture (dead code), py-spy (profiler), pre-commit hooks
- **CI:** GitHub Actions (`.github/workflows/`): format, lint, typecheck, test (coverage), security (Bandit + pip-audit), docs, js-test, deploy, docker-build, release

## Architecture

- **Pattern:** Flask app-factory (`create_app()` in `app/__init__.py`) + feature-folder blueprints (23 blueprints registered in the factory). Each domain (inspection, sample, case_file_generator, adjudication, etc.) is a package: `__init__.py` (Blueprint definition) + `routes.py` / `services.py` / `tasks.py` / `templates/` + optional `routes/` subpackage.
- **Data flow:** HTTP request → `before_request` (auth gate + audit-user stamping) → Blueprint route handler → Service-layer orchestrator → SQLAlchemy model (with FSO sync, audit hooks, FTS5 auto-index, Qdrant after_flush hook fired from session events) → (async) QStash/Celery → external sync target (Sheets/Airtable/Excel) or PDF generation.
- **Business logic location:** Service-layer classes in `app/services/` (`document_lifecycle.py::DocumentSaveCoordinator`, `sync_orchestrator.py::sync_row`, `sheets_sync.py::sync_to_sheets`, `neo4j_graph.py::Neo4jGraphService`, `version_control.py::VersionService`) and domain packages (`app/food_cell/services.py`, `app/case_file_generator/services.py`). Route files are thin: validation + delegation to a service/manager.
- **RAG pipeline architecture (Phase 1–5 + M3/M5):**
    - **Agent A (corpus/embedding):** `app/rag/ingestion.py::IngestionPipeline` (load → clean → dedup → chunk → embed → index) with injectable components; `app/rag/chunker.py` (LegalParagraphEngine), `app/rag/embedding_service.py`, `app/rag/qdrant_indexer.py` (after_flush hook), `app/rag/dedup.py` (SHA-256 fingerprint), `app/rag/document_classifier.py` (Phase 2, always wired), enrichment adapters (metadata/citation/crossref/entity/quality — all opt-in via `make_ingestion_pipeline`). Models: `LegalDocument`/`LegalChunk` (`app/models/rag.py`). Celery tasks: `rag.embed_and_index_task`, `rag.ingest_corpus_task`.
    - **Agent B (retrieval/generation/eval):** `app/rag/tasks.py` orchestrates: `run_retrieval_pipeline` (QueryClassifier → HybridRetriever [dense + sparse RRF, optional identifier route] → EnsembleReranker → RetrievalLogger) → `run_generation_pipeline` (ContextBuilder → PromptTemplate → GroundedLLMClient → CitationTracker → ResponseSanitizer → GenerationLogger → RAGResponse). Stub LLM mode (`RAG_USE_STUB_LLM=true`) for offline tests. Verification (`app/rag/verification/`) and evaluation (`app/rag/evaluation/`) are separate sub-packages. LangGraph agent (`app/rag/agent/`) — classify → retrieve → generate → verify → conditional expand-and-retry → finalize, with M5 review interrupt/human-in-the-loop.
    - **KG integration:** `kg/` package (corpus_ingestion, enrichment, queries, hybrid) + `app/services/neo4j_graph.py`; wired into generation via `RAG_KG_EXPANSION` (chunk→provision expansion) and `RAG_KG_FUSION` (query→provision contract RRF-fusion). Fail-closed write guard `NEO4J_ALLOW_WRITE`.
- **Models:** Split from monolithic `models.py` into `app/models/{auth,billing,config,document,food_cell,inspection,issue,ocr,rag,enrichment}.py`, re-exported by `app/models/__init__.py`. Optimistic concurrency via `version_id` columns (`__mapper_args__ = {"version_id_col": version_id}`) → `StaleDataError` → 409.
- **Shared abstractions:** `app/shared/case_resolver.py` (CaseFile/Adjudication ID disambiguation), `app/shared/document_case_manager.py` (parameterized CRUD + PDF for both case types), `app/shared/case_keys.py` (canonical field names), `app/shared/case_query_service.py`, `app/shared/context_derivers.py`.
- **Deployment topology (Render):** Two services — `food-adjudication-portal` (web, gunicorn, 2 sync workers, `flask db upgrade` on start) + `food-adjudication-celery-worker` (Celery worker, `SKIP_FSO_STARTUP_SYNC=1`). Plus a managed free-tier Postgres. Local dev: `docker-compose.yml` (web + worker + redis + postgres + flower).
- **Key patterns:** Lazy imports for all optional/heavy deps (Celery, langgraph, sentence-transformers, torch, gspread, pyairtable, msal, cloudinary, qdrant-client) so the app boots and degrades gracefully; config-first env-var resolution (Flask config read at call time, env-var fallback — `_flag_enabled` pattern); mock-injection for testability; SHA-256 hash-chained audit (`app/services/audit.py::log_audit` + `AuditLog` model); advisory-lock-protected audit writes on PostgreSQL; QStash webhook auth via `Upstash-Signature` (not session).

## Conventions (Observed)

- **Error handling:** Defensive try/except at every external-boundary call site (Sheets/Airtable/Excel sync, OCR, PDF generation, Qdrant, Neo4j, Celery task dispatch). No central `@app.errorhandler` is registered — errors are handled inline (rollback on DB errors, graceful degradation on external failures, JSON error responses from routes). Rollback on `db.session.commit()` failure; auto-heal missing tables via `db.create_all()` in app factory.
- **API design:** REST-style routes within Flask blueprints. JSON responses via `jsonify`. Auth-protected by global `before_request` gate (`require_login`) — all routes require login except an explicit `public_endpoints` set (health probe, lookup endpoints, QStash webhooks, RAG health). CSRF on all POST/PUT/DELETE via Flask-WTF (token in `<meta name="csrf-token">`, auto-attached to `fetch()` by global JS wrapper in `base.html`). QStash webhooks authenticated by `Upstash-Signature`, not session.
- **Type safety:** Partial typing — `pyproject.toml` has `Typing :: Typed` classifier but `mypy.pyright` config has `strict = false`; many modules are in the `mypy.overrides[].ignore_errors = true` list (route files, model modules, audit hooks). Dataclasses used for RAG pipeline results (`RetrievedChunk`, `SearchResult`, `RAGResponse`, `Citation` in `app/rag/retrieval/result.py`; `IngestedDocumentResult` in `ingestion.py`).
- **Response shapes:** RAG endpoints return the `RAGResponse` dataclass schema; route JSON returns `{message/status, ..., }`; QStash publish returns `{"mode": "async|sync", "message_id": ..., ...}`.
- **Naming:** Snake-case Python; camelCase DB columns in legacy models (`CaseFile.Food_Safety_Officer_Name` style preserved from original schema); canonical keys (`app/shared/case_keys.py`) bridge form data to DB columns; Flask endpoint names use blueprint-dotted names (`case_file_generator.index`).
- **Testing:** 2,616 tests collected (2026-08-18, `pytest --collect-only`); testpaths = `["tests", "legal_paragraph_detection_engine/tests"]`; conftest.py sets `DATABASE_URL` to an isolated temp SQLite, `SKIP_FSO_STARTUP_SYNC=1`, `DISABLE_PDF_GENERATION=1`, `RAG_USE_STUB_LLM=true`, and strips all `RAG_RERANKER_ENDPOINT`/`RAG_EMBED_ENDPOINT` env vars to isolate retrieval tests from remote inference. RAG tests run in stub-LLM mode (no Qdrant/network). Mock-injection pattern throughout (`encoder=`, `client=`, `pipeline=` constructor params). Heavy model deps (torch/CE) are lazy so unit tests never pay the import cost.
- **Logging:** `logging.getLogger(__name__)` per module; `app/utils/logging.py` configures structured output; best-effort logging of sync failures, OCR/CE degradation, QStash fallback — never blocks execution.
