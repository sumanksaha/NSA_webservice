## `yagni` — single-implementation abstractions

- **`app/shared/document_case_manager.py`** — 480-line fat parameterized wrapper; `_get_templates_to_generate()` branches on `case_type` string. Both `case_file` and `adjudication` use nearly identical render loops with different template paths/context builders. Two concrete modules could call shared primitives directly.
- **`app/shared/context_derivers.py`** — `derive_case_track()` returns hardcoded string, `derive_violations()` returns `[]` for adjudication. Dead indirection.
- **`app/shared/case_keys.py`** — string constants indexing into a dict built in the same function. Indirection with no consumers.
- **`app/utils/lookup.py`** — `lookup_fssai()` wraps `requests.get()` with try/except that swallows all errors. Stdlib `requests` + direct error handling suffices.
- **`app/services/sync_orchestrator.py`** — `sync_row()` dispatches on `"sample"`/`"non_sample"` to call `gspread`, `pyairtable`, or `msal`. Three sync targets, only Google Sheets ever configured. Airtable/Excel have **zero callers** beyond orchestrator dispatch. Delete Airtable/Excel, inline Google Sheets.
- **`app/utils/pdf_utils.py`** — `post_process_pdf_html()` 80 lines of regex-replacement imported in 12 files. Could be a single Jinja filter.
- **`app/plugins/registry.py`** — `PluginRegistry.get_instance()` singleton wrapping `importlib.import_module` for a `"rules"` plugin with exactly one implementation. Singleton over stdlib `importlib`.

## `native` — platform or stdlib replacement

- **`num2words`** → `app.utils.filters.to_words()` wraps a 3-line import. Inline with f-string for Indian currency.
- **`qstash` + `celery` + `redis`** → app uses **both** QStash (async dispatch) **and** Celery (sync fallback). `generate_case_file_route` calls Celery synchronously. Pick one. Delete celery+redis or qstash. ~3 deps gone.
- **`tenacity`** → 3-call-site retry wrapper (`@retry`) in cloudinary upload + OCR. Stdlib `while` loop + `time.sleep` suffices. 1 dep.
- **`chardet`** → `chardet.detect()` used in 1 place (`document_loader`). Python 3.12 stdlib `charset_normalizer` or `pathlib.read_text(errors="replace")` suffices.
- **`tqdm`** → used in 1 OCR batch script. Delete, use `logging.info`.
- **`psycopg2-binary`** + **`psycopg-binary`** → **two** PostgreSQL drivers. psycopg2 for SQLAlchemy URI, psycopg3-only for `langgraph-checkpoint-postgres` (lazy import). Use psycopg3 exclusively once langgraph checkpoint driver confirmed compatible. 1 dep removed.
- **`supabase>=2.0.0`** → "Phase 17: cloud-sync bridge (optional; app boots without it via lazy import)". Imported in one lazy block, called zero times. `yagni` + `delete` hybrid.

- **`app/food_cell/word_converter.py`** — 220-line class with `_add_heading`, `_add_paragraph`, `_add_table_row` (all 1-liners delegating to python-docx). Inline and delete ~180 lines.
- **RBAC gating** — `_rbac_docx_gate`, `_rbac_scope_for_case`, `_rbac_scope_for_form` in adjudication `routes.py` are 3 separate 12-line functions doing identical `scoped_officer_name(current_user)` check. Collapse to 1 helper.

## `stdlib` — hand-rolled replacements

- **`app/utils/lookup.py`:** `lookup_fssai` builds result namedtuple manually — use `dataclasses.dataclass` (stdlib).
- **`app/services/qstash_client.py`:** `make_dedup_key()` builds hash from kwargs — `hashlib.sha256` (stdlib) already used; `json.dumps(sort_keys=True)` cleaner than manual `repr` + `str()`.
- **`app/utils/sync.py`** — custom retry loop instead of stdlib retry.
