## This is a basic plan to implement a module that will sketch the way an FBO will implement the changes needed to address shortcomings

## Type of Jobs
	- easy
	- medium
	- hard

## Aim of the file:
	- this file will elaborate step by step implementstion of the process FBO will carried out to address shortcoming
	- the workfolw will ways start with easy steps, then medium and then hard steps

## Construction of the report
	- The report should start with a section called **Items to be purchased**
		- hairnet, apron and gloves if personal hygine is marked faulty or bad
		- temperature probe (range -20 C- 100C) for temperature monitoring if referigeration and thawing is marked bad or faulty
		- waterproof stickers if date tags or veg/non veg separeation are marked as missing
	- next, the workflow will be given, in the order of easy to medium to hard
	- then refrigeration and thawing protocol will be elaborated if refrigeration and thawing is marked bad
	- then cleaning protocol will be added if any - unclean premises, unclean equipment or unclean refrigerator is marked or bad

## Types of work

	### Easy
	 	- display of the license
		- display of the food safety display board for Restaurent URL - https://fssai.gov.in/docs/business/foodsafety/dl_Restaurant.jpg
        ### Medium
		- affix date tags on all stored containers and rewrite it when you add new items
		- separate veg and non veg processing area and utensils, if possible, and mark them accordingly
		- separate veg and non veg storage area and marked them accordingly
		- clean the premises daily
		- clean the refrigerator weekly
		- clean the utensils daily
		- clean the equipment daily
	### Hard
		- during cooking, monitor if the temperature of 75 C is maintained for 2 mins
		- during serving, hot food should be maintained at above 65 C
		- during serving, cold food should be maintained at below 5 C
		- for storage, bring the temperature from 60 to 21 c in 2 hrs and then referigerate
If possible , a flowchart can be drawn joining nodes
